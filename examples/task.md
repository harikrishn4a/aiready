## Example

## Feature
- ID: feat-003
- Title: User authentication — login and registration

## Scope — what will change
- Add POST /auth/login endpoint
- Add POST /auth/register endpoint
- Add JWT middleware for protected routes

## Exclusions — what will NOT change
- No OAuth or third-party auth
- No password reset flow
- No email verification

## Files expected to change
- src/auth/login.ts
- src/auth/register.ts
- src/auth/middleware.ts
- tests/auth.test.ts

## Verification standard
- `npm test` — all tests pass including tests/auth.test.ts
- `npm run typecheck` — zero type errors
- `npm run lint` — clean

## Acceptance criteria
- User can register with email and password
- User can login and receive a JWT token
- Protected routes return 401 for requests without a valid token

## Invariants — must remain true throughout
- Existing user endpoints must continue to pass their tests
- Database schema must not change
